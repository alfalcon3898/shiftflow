# ShiftFlow Developer Learning Journal

This folder documents **learning → independent mastery → shipped ShiftFlow work**. It is a study journal, not a claim of professional certification.

## Rules
- **Learning mode:** Study, ask questions, use notes and write code with guidance. Record *my own* explanations after each lesson.
- **Mastery mode:** Only after all required topics are practiced and reviewed. Complete a **new** challenge without ChatGPT guidance or personal notes; official documentation is allowed if the challenge permits it.
- **Build history:** Link commits, tests and pull requests showing what actually changed in ShiftFlow.
- A checked learning item means the concept was studied, **not** independently mastered.
- Only mark a mastery challenge passed when the implementation works, tests pass and I can explain it.
- Never record an unverified test result as passed.
